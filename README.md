# Ahyan Adatia

Computer Science and Artificial Intelligence student at the University of Nottingham (BSc, 2025 to 2028). I build full-stack products and applied AI systems, and I care about being able to show that they work: tests, CI and honest evaluation.

## Selected work

**[equity-forecast](https://github.com/ahyanadatia/stockpricepred)** · Python

Does an LSTM beat classical models at forecasting equity returns once you evaluate honestly? A walk-forward study of six models with Diebold-Mariano significance tests, a cost-aware backtest, and a positive control showing the harness detects signal when signal exists. 275 tests, strict type-checking, CI.

**Wove** · TypeScript, Next.js, Supabase, Anthropic API

AI outfit styling and a digital wardrobe, which I co-lead. Vision-based item recognition, a four-tier product image pipeline graded by a vision model, and outfit generation from wardrobe, taste profile and weather. Model output is validated with Zod and every table has row level security.

**[Forge](https://github.com/ahyanadatia/Forge)** · TypeScript, Next.js, Supabase

A track record for builders, computed from evidence. A deterministic scoring engine with anti-gaming detection, live verification probes against deployments and GitHub, and builder-to-project matching. 244 tests. Built with one collaborator.

**[Yuzu](https://github.com/ahyanadatia/yuzu)** · JavaScript, Postgres

A goals league for one flat, in about 1,200 lines with no framework. Postgres functions are the whole API, and the tables are locked down with row level security and no policies.
